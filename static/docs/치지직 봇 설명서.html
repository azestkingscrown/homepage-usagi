치지직 알림 봇 사용 설명서

커뮤니티 공지 및 생방송 시작 알림 서비스

최신 공식 가이드 보기 →

안내 사항

안내: 현재 봇은 최신 슬래시(/) 명령어 체계로 업그레이드되었습니다. 최신 사용법은 공식 사용 설명서를 참고해 주세요.

오류 발견 시 개발자에게 문의해 주시면 감사하겠습니다.

1. 봇 초대하기

서버 관리자 권한이 있는 사용자가 아래 링크를 통해 봇을 초대할 수 있습니다.

필수 권한 체크 항목

채널 보기 메시지 보내기 스레드에서 메시지 보내기 메시지 관리 링크 첨부 메시지 기록 보기 @everyone, @here, 모든 역할 멘션하기
봇 초대하기

2. 주요 명령어

접두사 !를 사용하여 명령어를 실행합니다. (최신 버전에서는 / 슬래시 명령어 지원)

명령어 설명 예시
!사용법 봇의 전체 명령어와 공지 사항 확인 !사용법
!등록 알림을 받을 스트리머를 현재 채널에 등록 !등록 강소연
!삭제 등록된 스트리머 알림을 해제 !삭제 강소연
!리스트 현재 채널의 알림 목록 확인 !리스트

3. 주요 기능 소개

1. 스마트 닉네임 검색

스트리머의 32자리 고유 ID를 몰라도 닉네임만으로 쉽게 등록이 가능합니다.

2. 실시간 생방송 썸네일

방송 시작 알림 시 캐시 문제를 해결하여 현재 방송 중인 실시간 화면을 임베드로 보여줍니다.

3. 원클릭 이동 버튼

알림 하단의 버튼을 통해 커뮤니티 공지 상세 페이지나 생방송 채널로 즉시 이동할 수 있습니다.

4. 안정적인 알림 시스템

SQLite 데이터베이스와 최적화된 스케줄러를 사용하여 API 차단 걱정 없이 빠르고 정확한 알림을 보냅니다.

4. 자주 묻는 질문 (FAQ)

Q. 알림이 오지 않아요!

A. 봇이 해당 채널에 메시지 보내기 및 링크 임베드 권한이 있는지 확인해 주세요. 권한이 없을 경우 명령어를 입력한 사용자에게 개인 메시지(DM)로 오류 안내가 발송됩니다.

Q. 닉네임으로 등록했는데 다른 사람이 등록돼요.

A. 검색 결과 중 인지도가 가장 높은 채널을 우선적으로 가져옵니다. 만약 결과가 다르다면 스트리머의 32자리 고유 ID를 입력해 주세요.
