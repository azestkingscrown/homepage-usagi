3. Key Features

1. Smart Nickname Search

Register streamers easily using just their nickname — no need to look up a 32-character channel ID.

2. Live Stream Thumbnails

Bypasses thumbnail caching to show a live preview frame of the active broadcast inside the Discord embed.

3. One-Click Action Buttons

Built-in buttons let viewers jump straight to the community post or live stream channel in one click.

4. High-Reliability Delivery

Powered by SQLite WAL storage and a distributed proxy scheduler for fast, accurate alerts without API rate-limit blocks.

4. Frequently Asked Questions (FAQ)

Q. I'm not receiving notifications!

A. Please verify that the bot has both Send Messages and Embed Links permissions in the target channel. If permissions are missing, an error notice is sent via Direct Message (DM) to the user who ran the command.

Q. I registered by nickname, but the wrong streamer was added.

A. Search results prioritize the most popular matching channel. If it picks the wrong channel, register directly using the streamer's 32-character Channel ID.
