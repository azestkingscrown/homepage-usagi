치지직 알림 봇 공식 사용 설명서

커뮤니티 공지 및 생방송 시작 실시간 알림 서비스

봇 초대하기 기술 문서

안내 사항 및 완전 익명 문의

오류 발견이나 기능 제안 시 개발자에게 문의해 주시면 빠르게 확인하겠습니다.

완전 익명 문의 시스템 운영 중

유저의 프라이버시 보호를 위해 1:1 익명 티켓 시스템을 운영하고 있습니다. 서버 입장 시 닉네임이 익명으로 자동 변경되며, 운영진과 1:1로 안전하게 상담하실 수 있습니다.

문의 서버 입장하기

1. 봇 초대하기

서버 관리자 권한이 있는 사용자가 공식 Discord 앱 디렉토리를 통해 봇을 초대할 수 있습니다.

필수 권한 체크 항목

채널 보기 메시지 보내기 링크 첨부 @everyone, @here, 모든 역할 멘션하기
Discord 봇 초대하기 데이터 수집 및 기술 문서 보기

2. 주요 명령어

디스코드 슬래시 접두사 /를 사용하여 명령어를 실행합니다.

명령어 설명 예시
/등록 알림을 받을 스트리머와 종류(선택)를 등록 /등록 [스트리머] [종류]
/알림메시지설정 알림 메시지와 멘션 역할 커스텀 설정 /알림메시지설정 [스트리머] [종류] ...
/사용법 봇의 전체 명령어와 공지 사항 확인 /사용법
/삭제 등록된 스트리머 알림을 해제 /삭제 [스트리머]
/리스트 현재 채널의 알림 목록 확인 /리스트
/핑 실시간 네트워크 상태 점검 /핑

작동 예시

봇이 실제로 작동하는 모습입니다. 치지직 생방송과 커뮤니티 새 글을 실시간으로 감지하여 깔끔한 임베드 알림을 전송합니다.

실시간 알림 작동 화면 예시 이미지는 운영 환경의 /uploads/ 경로에 배치하여 표시할 수 있습니다.

3. 주요 기능 소개

1. 스마트 닉네임 검색

스트리머의 32자리 고유 ID를 몰라도 닉네임만으로 쉽게 등록이 가능합니다.

2. 실시간 생방송 썸네일

방송 시작 알림 시 캐시 문제를 해결하여 현재 방송 중인 실시간 화면을 임베드로 보여줍니다.

3. 원클릭 이동 버튼

알림 하단 버튼을 통해 커뮤니티 공지 상세 페이지나 생방송 채널로 즉시 이동할 수 있습니다.

4. 안정적인 알림 시스템

SQLite WAL 데이터베이스와 분산 프록시 스케줄러를 사용하여 API 차단 걱정 없이 빠르고 정확한 알림을 보냅니다.

4. 자주 묻는 질문 (FAQ)

Q. 알림이 오지 않아요!

A. 봇이 해당 채널에 메시지 보내기 및 링크 첨부 권한이 있는지 확인해 주세요. 권한이 없을 경우 명령어를 입력한 사용자에게 개인 메시지(DM)로 오류 안내가 발송됩니다.

Q. 닉네임으로 등록했는데 다른 사람이 등록돼요.

A. 검색 결과 중 인지도가 가장 높은 채널을 우선적으로 가져옵니다. 만약 결과가 다르다면 스트리머의 32자리 고유 ID를 입력해 주세요.
